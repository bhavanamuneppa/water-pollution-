# water-pollution-
📘 Overview

This project applies a Convolutional Neural Network (CNN) to classify water body images as clean or polluted, promoting sustainability and environmental awareness.
In Week 2, the focus was on developing, training, and evaluating the CNN model using the preprocessed dataset from Week 1.

🎯 Objectives

Build and train a CNN model for binary image classification

Use data augmentation to improve generalization

Evaluate the model using accuracy and loss metrics

Visualize training and validation performance

🧠 Week 2 Progress

Implemented a CNN with convolution, pooling, and dropout layers

Trained the model on clean and polluted water image data

Monitored performance using training/validation accuracy and loss graphs

Saved the trained model for future fine-tuning and deployment

🛠 Tools

Python, TensorFlow, Keras, Matplotlib, NumPy
